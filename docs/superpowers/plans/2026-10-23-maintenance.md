# 小程序遗留问题修复计划

**目标：** 修复已确认的支付、登录、云凭据、记录及设备页面问题，并重新在微信开发者工具验收。

**实现约定：** 沿用 `/api/v2` 和微信业务 Bearer 身份；普通请求仅在明确 401 时最多重登录和重放一次，不重试网络失败的业务写请求。文件价格和已解锁状态从后端读取，路由参数和本地已购缓存不作为免费依据；新文件保存拍摄时的设备收费金额，无法确认金额的历史文件明确提示。支付结果须经服务端查询确认后才能标记解锁。视频预览保留现有产品行为。

**技术：** uni-app、Vue3、TypeScript、Vitest、Yii2/PHPUnit。小程序与后端分别检查差异；不覆盖当前后端和 Web 管理端其他会话的未提交修改。本轮不提交、推送或发布。

- [x] 登录：先新增失败响应、坏缓存、并发 401、刷新失败和非本域隔离测试，确认失败后修复，运行相关测试。
- [x] 云存储：先复现过期及并发行为，再修复 STS 更新和微信 SDK 适配；解决字体请求；验证兼容的依赖安全更新。
- [x] 页面：先覆盖记录重新显示/下拉刷新、设备目录失败、分页和轮询退出，再修复；清理敏感调试输出及不支持的组件样式选择器。
- [x] 支付：先覆盖 Bearer、收费/免费/未知金额和已支付校验；后端限制文件所有权与解锁写入，保存新文件价格；前端读取服务端状态，移除本地免费捷径。
- [x] 验证：运行完整小程序测试、类型检查、只读 lint、微信构建及后端相关单元测试；独立审查差异并修正问题。
- [x] 开发工具复测：首页、记录、我的、关联设备、配置读取和支付页状态；不进行真实支付、录制、设备配置保存或发布。

验证命令：在小程序目录执行 `pnpm test`、`pnpm run tsc`、`pnpm exec eslint . --ext .vue,.js,.jsx,.cjs,.mjs,.ts,.tsx,.cts,.mts --ignore-path .gitignore`、`pnpm run build:mp-weixin`。后端通过 `php api/vendor/bin/phpunit --bootstrap api/tests/_bootstrap.php api/tests/unit/components/MiniProgramFileAccessTest.php` 及既有相关测试验证。

## 维护结果与发布边界

- 云凭据除到期检查外，还由当前有效 STS 计算签名，避免 COS SDK 的内部缓存绕过刷新；真实微信 SDK 用例已覆盖跨五分钟换凭据。
- 开发工具实测发现 DCloud 将动态导入转换为 `await "./request.js"`，源码测试无法捕获。认证与业务请求已改为静态导入，并新增构建产物执行验证，检查真实 CommonJS 请求模块、401 登录恢复和资料请求。
- `node scripts/verify-mp-build.cjs` 的三项产物冒烟检查通过；分别还原列表和 401 的错误产物后均能可靠失败，已接入微信 CI 和发布构建。
- 字体 URL 单独返回 HTTP 200 仍无法消除开发工具的 `ERR_CACHE_MISS`；当前组件实际只使用图片图标，已移除未使用的全局字体加载，保留可选样式的 HTTPS 地址。
- 小程序源码测试 30 个文件、336 项通过；类型检查、只读 ESLint、微信和 H5 构建通过。后端相关测试 45 项中 37 项通过、8 项因本机没有 Redis 跳过，129 个断言。
- 微信开发者工具 Nightly v2.01.2512242、基础库 3.17.5 复测：首页、用户信息、17 条历史记录及缩略图、3 台关联设备、设备 55 的配置及场景正常；历史文件下载页显示“待确认”并禁用支付。最终配置页控制台无运行错误，剩余警告为工具热重载、SharedArrayBuffer 与灰度基础库提示，原字体和组件 WXSS 告警已消除。
- 静态导入后的微信构建仍提示认证模块之间的 Circular chunk；CommonJS 产物的列表、401、资料请求已实际执行通过，开发工具冷编译流程亦验证通过。当前没有发布构建或真机支付验证的替代结论。
- 独立复核未发现确定的 P1/P2 阻塞；支付回调测试使用 EasyWechat 的真实加密通知处理，只替换出站查询，覆盖成功、未支付、错账号、金额不符和服务端未确认时要求重试。
- pnpm 冻结安装已验证。审计从 5 critical / 73 high 降到 0 critical / 1 high / 25 moderate / 11 low；唯一 high 为开发 glob 依赖链中的 [braces 上游未修复漏洞](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)，不能视作依赖告警全部清零。

上线前必须先在后端执行 `m261023_150000_add_download_price_to_file`，再部署对应文件和支付接口，最后发布小程序。历史未知金额保留 `NULL`，核实后才能补价；不会自动按免费处理。本轮没有执行线上迁移、发布、真实支付、录制或设备配置保存；真机支付和回调联调仍须在部署后验收。
